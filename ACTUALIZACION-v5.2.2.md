# v5.2.2 Control online estable
- Espera el primer estado del propio jugador antes de enviar la dirección inicial; si el jugador ya movió el joystick, conserva su instrucción. El servidor incluye el rumbo objetivo únicamente del propio jugador, con respaldo a la orientación visible para servidores anteriores.
- Un dedo controla el joystick y otro el turbo de forma independiente. En online, tocar o arrastrar el terreno con otro dedo no gira el gusano; con ratón sigue disponible el giro por arrastre cuando no se usa el joystick. Al soltar el joystick, el gusano sigue avanzando en la última dirección (regla existente).
- Cabeza, cuerpo y cámara usan posiciones interpoladas del servidor. Se desactiva la predicción local que desplazaba la cabeza por separado y podía provocar correcciones visibles. Puede aumentar el retraso visual si la red tiene ping alto; no se cambia la frecuencia de red, velocidad, colisiones ni IA.
- El servidor ignora órdenes de conexiones sustituidas y órdenes durante la espera. Se libera el turbo al perder foco o minimizar; si el paquete no llega, permanece el límite de seguridad de turbo en el servidor.
- No se cambian audio, micrófono, gráficos, cuentas, base de datos, dirección oficial ni firma. Probar con dos teléfonos, joystick + turbo y micrófono, giros a 180 grados, reconexión y portales. Pruebas locales no equivalen a pruebas Android reales.
