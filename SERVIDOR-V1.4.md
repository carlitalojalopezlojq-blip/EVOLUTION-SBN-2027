# Servidor permanente de pruebas
El APK necesita una URL wss:// válida para las cuentas y salas. GitHub Actions compila el APK, pero no aloja el servidor de juego. Usa un alojamiento Node.js con WebSocket, TLS y disco persistente. Configura el comando `npm install --omit=dev` y el inicio `npm start`. Define PORT según el proveedor y ACCOUNTS_FILE como ruta absoluta dentro del volumen persistente, por ejemplo /data/accounts.json. Restringe el acceso a ese archivo, realiza copias protegidas y nunca lo subas a GitHub. Usa una sola instancia mientras se utilice el almacenamiento JSON actual. Configura el proxy TLS para aceptar Upgrade WebSocket y conexiones largas. Comprueba la URL HTTPS y luego crea una cuenta de prueba desde el APK con la URL wss correspondiente. No hay servidor desplegado todavía. No se recomienda publicar masivamente sin pruebas de concurrencia, recuperación, seguridad y copias de respaldo.
