# v5.1 Premium Interface (beta)
- Rediseño de navegación, paneles independientes con retorno, iconos vectoriales y 33 ilustraciones SVG originales de arenas, modos y jefes (no fotografías). Las frutas conservan sus sprites. El motor y los audios existentes se conservan.
- Perfiles directos 2D económico (30 FPS), 2D fluido (60), 3D bajo, equilibrado, alto, ultra y automático. FPS son objetivos, no garantías. Opciones antiguas siguen disponibles.
- Registro: correo obligatorio y único, usuario permanente de 3–20 caracteres ASCII (letras, números, guion y guion bajo; sin espacios), contraseña de 8–128. Se normalizan usuario y correo a minúsculas. La contraseña se almacena con scrypt como antes. El correo no se muestra a otros jugadores. NO se verifica por correo ni se usa para restablecer contraseña; falta integrar un servicio de envío de correo antes de un lanzamiento público. Las cuentas existentes conservan sus datos y pueden vincular un correo tras iniciar sesión. La base de datos añade un UUID único y estable para cada cuenta; el ID local de invitado no sirve para buscar jugadores.
- Buscar/agregar amigos por ID desde Social, copiar ID en Cuenta y Perfil, invitar por ID en la partida. Los contactos locales anteriores no se borran; añadir amigo online sigue siendo un contacto unilateral, no una solicitud con aceptación.
- Cristales de mutación: primer intento a 60 s de simulación; posteriores cada 90–150 s. Máximo dos simultáneos; duran hasta 240 s. Coordenadas aleatorias del mapa, se recogen por contacto; bots no pueden recogerlos; mutación y aura/poder se aplican inmediatamente. Disponibles offline en modos no competitivos compatibles, y online en supervivencia/invasión con reglas avanzadas. No se añaden a torneos. Las cuentas online solo pueden equipar al inicio mutaciones ya registradas en su ADN; invitados pueden descubrirlas en la partida. El color elegido de piel conserva prioridad.
- Render y Neon: no se modifican variables ni credenciales. La migración es aditiva y se ejecuta al inicializar el servicio. No borra tablas ni perfiles. Todos deben instalar v5.1: el registro anterior sin correo ya no se admite.
- Pruebas locales del motor y SQL simulado. No se ha probado PostgreSQL real ni APK Android; verificar cloud:true después del despliegue y registrar una cuenta de prueba. Verificar inicio de sesión, ID estable, búsqueda y adición de amigo, selección 2D/3D y mutaciones. La interfaz no pudo abrirse en el navegador de prueba por bloqueo del entorno.
